Set up once, used by everyone An author publishes the procedure; reviewers, auditors and admins each work with it from their own role.

  • Admin×+

    Runs the workspace: people, tools and access.

    • Manage members and roles
    • Connect tools and manage secrets
    • See every run and decision
  • Author×+

    Writes and tests procedures.

    • Write and upload procedures
    • Run evals in sandbox
    • Publish new versions
  • Reviewer×+

    Decides on paused runs.

    • Work the review queue
    • Approve or escalate paused runs
    • Add a reason to every decision
  • Auditor×+

    Has read-only access to the workspace.

    • Read every run, version and decision
    • Verify the audit log
    • Change nothing

Decide who can do what Authors write, reviewers decide and auditors only read, with roles set for each workspace.
